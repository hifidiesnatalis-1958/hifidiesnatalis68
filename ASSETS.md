# Aset Kasundaan untuk website

Sumber: [Canva Dies NUT!](https://www.canva.com/design/DAHSvGQu70w/94wi7gCJy0CH8NBvGlQ4yQ/edit), melalui PDF Cetak 81 halaman yang diberikan pengguna.

Identitas asli tersedia di `public/assets/kasundaan/`: logo 68, logo ilustrasi, logo atom, bagian kujang, empat ornamen sudut, motif megamendung dan floral, wordmark, bunga, sulur emas/merah, serta detail dekoratif. Foto produk mencakup T-shirt, totebag, keychain, dan motif stiker. Poster lomba online, tautan lomba, open performance, merchandise, filosofi logo dan makna warna mempertahankan teks sumber.

`manifest.json` memetakan setiap file ke halaman dan image xref PDF, berikut ukuran serta jumlah byte. Website memuat 27 turunan WebP lokal dengan total sekitar 4,94 MB untuk seluruh koleksi. Aset transparan memakai kompresi lossless; poster dan tekstur menggunakan turunan WebP berkualitas tinggi. Ukuran tampilan dibatasi sesuai kebutuhan web dan tidak memperbesar gambar sumber.
